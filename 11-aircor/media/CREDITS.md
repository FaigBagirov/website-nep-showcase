# Источники фото и видео — вариант 11 (aircor)

Все файлы — Pexels (лицензия Pexels: бесплатно, в т.ч. коммерческое использование, атрибуция не обязательна). Источники только Pexels; чужие фото с сайта-образца не использованы. Оригиналы (JPEG/MP4) лежат в `media/_download/` (в git не входят, `.gitignore`); в проект идут обработанные WebP (обрезка под слот, 2 ширины для srcset, ≤300 КБ) и один MP4. Имя автора взято из имени файла загрузки на странице Pexels (может отличаться от отображаемого имени профиля); страница источника — `https://www.pexels.com/photo/<id>/`. Все файлы проверены по сигнатуре (JPEG `FF D8 FF`, MP4 `ftyp`), ничего не запускалось.
