# Источники фото — вариант 12 (Stott)

Все файлы — Pexels (лицензия Pexels: бесплатно, в т.ч. коммерческое использование, атрибуция не обязательна; указываем автора из вежливости). Фото с сайта-образца и чужих сайтов не использованы. Оригиналы (JPEG) лежат в `media/_download/` (в git не идут, `.gitignore`); на сайте — обрезанные WebP (2 ширины для srcset, ≤300 КБ). Все файлы проверены по сигнатуре (JPEG `FF D8 FF`), ничего скачанного не запускалось.
